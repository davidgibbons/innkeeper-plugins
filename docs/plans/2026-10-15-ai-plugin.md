# AI Services Part 3: The `ai` Plugin Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A new `ai` plugin where one instance is one connection to a model. It offers `ai.chat` and `ai.embed` to other plugins, lists the provider's models for the model field, and tests the connection from the settings page.

**Architecture:** Section 3 of the core spec `docs/superpowers/specs/2026-10-15-ai-services-design.md`.
- The plugin speaks the protocol from core plans 1 (`2026-10-15-ai-capability.md`) and 2 (`2026-10-15-settings-form.md`).
- The provider setup and the streaming loop are copied from forge-ai: `settings.go`, plus `stream` and `mergeToolCalls` from `chat.go`. Plan 4 removes them from forge-ai.
- Each kind the owner can tick (`chat`, `embed`) is one entry in a `kinds` table: its service method, its label in Test's report, and its probe. Adding a kind means adding a row.

**Tech Stack:** Go, any-llm-go v0.9.0, JSON-RPC over stdio, `net/http/httptest` for a fake OpenAI-compatible server.

**Prerequisite:** core plans 1 and 2 are merged to the core's `main` and pushed. This repo pins the core by commit (see the README's "The core version is pinned in `go.mod`"). Task 1 moves the pin. Don't commit a `replace` directive: CI fetches the core from GitHub.

**Deviations from the spec:**
- **`image` isn't offered as a kind.** Plan 1 left `ai.image` out of `protocol.Services`, so an `image` checkbox could only ever be refused. Add it when a provider supports image generation.
- **`kinds` values are `chat` and `embed`, not method names.** The checkbox group shows enum values as they are, so the config uses short words. The `kinds` table maps each to `protocol.MethodAIChat` or `protocol.MethodAIEmbed`, and `initialize` reports the methods.
- **`forge-ai/stream.go` doesn't move.** It parses the JSON a forge-ai prompt asks for, which is forge-ai's concern. The provider-side stream loop is `stream` and `mergeToolCalls` in `forge-ai/chat.go`, and those move. Stripping `<think>` stays with the consumer too: `ai.chat` returns the model's text unchanged.
- **Retrying without tools is the consumer's job.** The provider answers a refused request with `protocol.CodeAIRejected`, and forge-ai decides whether to retry.
- **A bad config fails `initialize`.** forge-ai kept the error for the first run. Here the instance shows as broken, and its Check button reports the error. An empty config, which the core's settings process sends, initializes with no services.
- **Embeddings are refused at setup for a provider that doesn't offer them,** such as anthropic or groq, so Test and Check catch it before a consumer does.

**Tests:** No database. `go test ./ai/` runs everything here.

```go
func (f *fakeLLM) ServeHTTP(w http.ResponseWriter, r *http.Request) {
	var body map[string]any

		if err := json.NewDecoder(r.Body).Decode(&body); err != nil {
			http.Error(w, err.Error(), 400)
			return
		}
	}

// host is a fake Innkeeper core: it talks to the plugin over pipes and
// records the ai.delta notifications it gets.
type host struct {
	conn   *protocol.Conn
	mu     sync.Mutex
	deltas []protocol.AIDelta
}

// start runs the plugin and initializes it with config.
func start(t *testing.T, config map[string]any) (*host, protocol.InitializeResult, error) {
	t.Helper()
	toPlugin, fromHost := io.Pipe()
	toHost, fromPlugin := io.Pipe()
	srv := &server{}
	srv.conn = protocol.NewConn(toPlugin, fromPlugin, srv.handle)
	h := &host{}
	h.conn = protocol.NewConn(toHost, fromHost, func(ctx context.Context, method string, params json.RawMessage) (any, error) {
		if method != protocol.NotifyAIDelta {
			return nil, protocol.MethodNotFound(method)
		}
		var d protocol.AIDelta
		_ = json.Unmarshal(params, &d)
		h.mu.Lock()
		h.deltas = append(h.deltas, d)
		h.mu.Unlock()
		return nil, nil
	})
	ctx, cancel := context.WithCancel(context.Background())
	go srv.conn.Run(ctx)
	go h.conn.Run(ctx)
	t.Cleanup(func() {
		cancel()
		fromHost.Close()
		fromPlugin.Close()
	})
	var res protocol.InitializeResult
	err := h.conn.Call(ctx, protocol.MethodInitialize, protocol.InitializeParams{Protocol: 1, Config: config}, &res)
	return h, res, err
}

// started is start for a config that must initialize.
func started(t *testing.T, config map[string]any) *host {
	t.Helper()
	h, _, err := start(t, config)
	if err != nil {
		t.Fatal(err)
	}
	return h
}

func (h *host) call(method string, params, result any) error {
	return h.conn.Call(context.Background(), method, params, result)
}

// rpcCode is err's JSON-RPC code, or 0.
func rpcCode(err error) int {
	var rpcErr *protocol.Error
	if errors.As(err, &rpcErr) {
		return rpcErr.Code
	}
	return 0
}

func TestInitializeReportsTickedKinds(t *testing.T) {
	cases := []struct {
		name   string
		config map[string]any
		want   []string
	}{
		{"default", map[string]any{"provider": "ollama", "model": "m"}, []string{protocol.MethodAIChat}},
		{"both", map[string]any{"provider": "ollama", "model": "m", "kinds": []any{"embed", "chat"}},
			[]string{protocol.MethodAIChat, protocol.MethodAIEmbed}},
		{"settings process", map[string]any{}, nil},
	}
	for _, c := range cases {
		_, res, err := start(t, c.config)
		if err != nil {
			t.Fatalf("%s: %v", c.name, err)
		}
		if !slices.Equal(res.Services, c.want) || res.Name != "ai" || !slices.Equal(res.Capabilities, []string{"ai", "settings"}) {
			t.Errorf("%s: initialize = %+v, want services %v", c.name, res, c.want)
		}
	}
}

func TestInitializeRefusesABadConfig(t *testing.T) {

		t.Fatalf("err = %v, want one about the model", err)
```

```go
// settings are one connection's config.
type settings struct {
	Provider string   `json:"provider"`
	BaseURL  string   `json:"base_url"`
	Model    string   `json:"model"`
	Kinds    []string `json:"kinds"`
}

// kind is one thing a connection can be for.
type kind struct {
	service string
	label   string
}

// kinds are the values of the config's kinds, each with the service it
// offers and its name in Test connection's report.
var kinds = map[string]kind{
	"chat":  {protocol.MethodAIChat, "Chat"},
	"embed": {protocol.MethodAIEmbed, "Embeddings"},
}

// parseSettings reads a config. It doesn't require a model, since listing
// the provider's models comes before choosing one.
func parseSettings(cfg map[string]any) (settings, error) {
	var s settings
	b, err := json.Marshal(cfg)
	if err == nil {
		err = json.Unmarshal(b, &s)
	}
	if err != nil {
		return s, fmt.Errorf("settings: %w", err)
	}
	if _, ok := providers[s.Provider]; !ok {
		return s, fmt.Errorf("settings: provider %q isn't one of %s", s.Provider, strings.Join(slices.Sorted(maps.Keys(providers)), ", "))
	}
	if len(s.Kinds) == 0 {
		s.Kinds = []string{"chat"}
	}
	for _, k := range s.Kinds {
		if _, ok := kinds[k]; !ok {
			return s, fmt.Errorf("settings: kind %q isn't one of %s", k, strings.Join(slices.Sorted(maps.Keys(kinds)), ", "))
		}
	}
	return s, nil
}

// services are the service methods the connection offers, sorted.
func (s settings) services() []string {
	var out []string
	for _, k := range s.Kinds {
		out = append(out, kinds[k].service)
	}
	slices.Sort(out)
	return slices.Compact(out)
}

type newProvider func(...config.Option) (anyllm.Provider, error)

// wrap turns a provider package's New into a newProvider.
func wrap[P anyllm.Provider](f func(...config.Option) (P, error)) newProvider {
	return func(opts ...config.Option) (anyllm.Provider, error) {
		p, err := f(opts...)
		if err != nil {
			return nil, err
		}
		return p, nil
	}
}

var providers = map[string]newProvider{
	// For vLLM, llama.cpp servers, LM Studio, and OpenRouter, with or without a key.
	"openai-compatible": wrap(func(opts ...config.Option) (*openai.CompatibleProvider, error) {
		return openai.NewCompatible(openai.CompatibleConfig{Name: "openai-compatible"}, opts...)
	}),
	"openai":    wrap(openai.New),
	"anthropic": wrap(anthropic.New),
	"gemini":    wrap(gemini.New),
	"mistral":   wrap(mistral.New),
	"groq":      wrap(groq.New),
	"deepseek":  wrap(deepseek.New),
	"ollama":    wrap(ollama.New),
	"llamacpp":  wrap(llamacpp.New),
	"llamafile": wrap(llamafile.New),
}

// provider builds the configured any-llm-go provider. Providers that need
// a key fail here without one.
func (s settings) provider(apiKey string) (anyllm.Provider, error) {
	if s.Provider == "openai-compatible" && s.BaseURL == "" {
		return nil, errors.New("settings: openai-compatible needs a base_url")
	}
	// A long generation on a local model can stream for many minutes; the
	// caller's context is what bounds it.
	opts := []config.Option{config.WithTimeout(time.Hour)}
	if apiKey != "" {
		opts = append(opts, config.WithAPIKey(apiKey))
	}
	if s.BaseURL != "" {
		opts = append(opts, config.WithBaseURL(s.BaseURL))
	}
	p, err := providers[s.Provider](opts...)
	if err != nil {
		return nil, fmt.Errorf("settings: %w", err)
	}
	return p, nil
}

// embeds reports whether llm can embed. Some providers share an
// implementation with an Embedding method but declare they host no
// embedding models.
func embeds(llm anyllm.Provider) bool {
	if _, ok := llm.(anyllm.EmbeddingProvider); !ok {
		return false
	}
	c, ok := llm.(anyllm.CapabilityProvider)
	return !ok || c.Capabilities().Embedding
}

// listsModels reports whether llm can list its models, on the same terms
// as embeds.
func listsModels(llm anyllm.Provider) bool {
	if _, ok := llm.(anyllm.ModelLister); !ok {
		return false
	}
	c, ok := llm.(anyllm.CapabilityProvider)
	return !ok || c.Capabilities().ListModels
}
```

```go
// Command ai offers model services to other plugins, ai.chat and ai.embed,
// through any-llm-go. One instance is one connection to a model.
package main

import (
	"context"
	"encoding/json"
	"errors"
	"fmt"
	"os"
	"slices"
	"sync/atomic"

	"github.com/inkandale/innkeeper/protocol"
	anyllm "github.com/mozilla-ai/any-llm-go"
)

const version = "0.1.0"

// connection is what initialize configured. llm is nil for the empty config
// the core's settings process starts with.
type connection struct {
	settings settings
	llm      anyllm.Provider
}

type server struct {
	conn *protocol.Conn
	// Set by initialize; requests run on other goroutines.
	cur atomic.Pointer[connection]
}

func main() {
	srv := &server{}
	srv.conn = protocol.NewConn(os.Stdin, os.Stdout, srv.handle)
	if err := srv.conn.Run(context.Background()); err != nil {
		fmt.Fprintln(os.Stderr, err)
		os.Exit(1)
	}
}

func (srv *server) handle(ctx context.Context, method string, params json.RawMessage) (any, error) {
	switch method {
	case protocol.MethodInitialize:
		var p protocol.InitializeParams
		if err := json.Unmarshal(params, &p); err != nil {
			return nil, invalid("%v", err)
		}
		c, err := connect(p.Config, p.Secrets["api_key"])
		if err != nil {
			return nil, err
		}
		srv.cur.Store(c)
		return protocol.InitializeResult{Protocol: protocol.Version, Name: "ai", Version: version,
			Capabilities: []string{"ai", "settings"}, Services: c.services()}, nil
	case protocol.MethodShutdown:
		return nil, nil
	}
	return nil, protocol.MethodNotFound(method)
}

// connect builds the connection a config describes. An empty config gives
// a connection that offers nothing.
func connect(cfg map[string]any, apiKey string) (*connection, error) {
	if len(cfg) == 0 {
		return &connection{}, nil
	}
	s, err := parseSettings(cfg)
	if err != nil {
		return nil, err
	}
	if s.Model == "" {
		return nil, errors.New("settings: model is required")
	}
	llm, err := s.provider(apiKey)
	if err != nil {
		return nil, err
	}
	if slices.Contains(s.Kinds, "embed") && !embeds(llm) {
		return nil, fmt.Errorf("settings: %s doesn't offer embeddings", s.Provider)
	}
	return &connection{settings: s, llm: llm}, nil
}

// services are what the connection offers; none before it's configured.
func (c *connection) services() []string {
	if c.llm == nil {
		return nil
	}
	return c.settings.services()
}

// offering returns the connection when it offers method.
func (srv *server) offering(method string) (*connection, error) {
	c := srv.cur.Load()
	if c == nil || !slices.Contains(c.services(), method) {
		return nil, protocol.MethodNotFound(method)
	}
	return c, nil
```

```go
func (srv *server) chat(ctx context.Context, params json.RawMessage) (any, error) {
	c, err := srv.offering(protocol.MethodAIChat)
	if err != nil {
		return nil, err
	}
	var p protocol.AIChatParams
	if err := json.Unmarshal(params, &p); err != nil || len(p.Messages) == 0 {
		return nil, invalid("ai.chat needs messages")
	}
	req, err := completionParams(c.settings.Model, p)
	if err != nil {
		return nil, invalid("%v", err)
	}
	text, calls, err := stream(ctx, c, req, func(piece string) {
		if p.Run != "" {
			_ = srv.conn.Notify(protocol.NotifyAIDelta, protocol.AIDelta{Run: p.Run, Text: piece})
		}
	})
	if err != nil {
		return nil, modelError(err)
	}
	res := protocol.AIChatResult{Text: text, Model: c.settings.Model}
	for _, tc := range calls {
		res.ToolCalls = append(res.ToolCalls, protocol.ToolCall{ID: tc.ID, Name: tc.Function.Name, Arguments: tc.Function.Arguments})
	}
	return res, nil
}

// completionParams converts an ai.chat request to any-llm-go's.
func completionParams(model string, p protocol.AIChatParams) (anyllm.CompletionParams, error) {
	req := anyllm.CompletionParams{Model: model, Temperature: p.Temperature, MaxTokens: p.MaxTokens}
	for _, m := range p.Messages {
		msg := anyllm.Message{Role: m.Role, Content: m.Content, ToolCallID: m.ToolCallID}
		if len(m.Parts) > 0 {
			parts := make([]anyllm.ContentPart, 0, len(m.Parts))
			for _, part := range m.Parts {
				cp := anyllm.ContentPart{Type: part.Type, Text: part.Text}
				if part.ImageURL != "" {
					cp.ImageURL = &anyllm.ImageURL{URL: part.ImageURL}
				}
				parts = append(parts, cp)
			}
			msg.Content = parts
		}
		// ponytail: any-llm-go's per-provider ToolCall.Extra (Gemini's thought
		// signatures) doesn't cross ai.chat, so a Gemini tool loop loses its
		// reasoning between turns; carry it in protocol.ToolCall if that bites.
		for _, tc := range m.ToolCalls {
			msg.ToolCalls = append(msg.ToolCalls, anyllm.ToolCall{ID: tc.ID, Type: "function",
				Function: anyllm.FunctionCall{Name: tc.Name, Arguments: tc.Arguments}})
		}
		req.Messages = append(req.Messages, msg)
	}
	for _, t := range p.Tools {
		var schema map[string]any
		if err := json.Unmarshal(t.Parameters, &schema); err != nil {
			return req, fmt.Errorf("tool %s: parameters: %w", t.Name, err)
		}
		req.Tools = append(req.Tools, anyllm.Tool{Type: "function",
			Function: anyllm.Function{Name: t.Name, Description: t.Description, Parameters: schema}})
	}
	return req, nil
}

// stream runs one streamed request, passing each piece of text to onText,
// and returns the whole text and any tool calls.
func stream(ctx context.Context, c *connection, params anyllm.CompletionParams, onText func(string)) (string, []anyllm.ToolCall, error) {
	params.Stream = true
	chunks, errs := c.llm.CompletionStream(ctx, params)
	var text strings.Builder
	var calls []anyllm.ToolCall
	for chunk := range chunks {
		for _, ch := range chunk.Choices {
			if ch.Delta.Content != "" {
				text.WriteString(ch.Delta.Content)
				onText(ch.Delta.Content)
			}
			calls = mergeToolCalls(c.settings.Provider, calls, ch.Delta.ToolCalls)
		}
	}
	if err := <-errs; err != nil {
		return "", nil, err
	}
	return text.String(), calls, ctx.Err()
}

// mergeToolCalls adds streamed tool call deltas to calls. any-llm-go passes
// on each provider's own streaming shape, with no index to match on:
//   - anthropic resends the whole call so far under its ID;
//   - ollama sends whole calls, numbered within each chunk, so IDs repeat;
//   - the rest send whole calls with unique IDs, or OpenAI-style fragments
//     whose first carries the ID and later ones carry it or nothing.
func mergeToolCalls(provider string, calls, deltas []anyllm.ToolCall) []anyllm.ToolCall {
	for _, d := range deltas {
		d.Type = "function"
		i := slices.IndexFunc(calls, func(c anyllm.ToolCall) bool { return d.ID != "" && c.ID == d.ID })
		switch {
		case provider == "ollama" || len(calls) == 0 || (d.ID != "" && i < 0):
			calls = append(calls, d)
		case provider == "anthropic" && i >= 0:
			calls[i] = d
		default:
			if i < 0 {
				i = len(calls) - 1
			}
			calls[i].Function.Name += d.Function.Name
			calls[i].Function.Arguments += d.Function.Arguments
		}
	}
	return calls
}

// modelError gives a model failure the code a consumer branches on: a
// refused request, which retrying won't fix, or a retryable one.
func modelError(err error) error {
	switch {
	case errors.Is(err, llmerrors.ErrInvalidRequest), errors.Is(err, llmerrors.ErrUnsupportedParam):
		return protocol.NewError(protocol.CodeAIRejected, err.Error(), false)
	case errors.Is(err, llmerrors.ErrRateLimit), errors.Is(err, context.DeadlineExceeded):
		return protocol.NewError(protocol.CodeInternalError, err.Error(), true)
	}
	return err
}
```

```go
// embedTexts returns one vector per text, in the texts' order. connect
// already checked the provider embeds.
func embedTexts(ctx context.Context, c *connection, texts []string) ([][]float32, error) {
	res, err := c.llm.(anyllm.EmbeddingProvider).Embedding(ctx, anyllm.EmbeddingParams{Model: c.settings.Model, Input: texts})
	if err != nil {
		return nil, err
	}
	if len(res.Data) != len(texts) {
		return nil, fmt.Errorf("the provider returned %d vectors for %d texts", len(res.Data), len(texts))
	}
	vectors := make([][]float32, len(texts))
	for _, d := range res.Data {
		if d.Index < 0 || d.Index >= len(texts) || vectors[d.Index] != nil {
			return nil, fmt.Errorf("the provider returned vector %d for %d texts", d.Index, len(texts))
		}
		v := make([]float32, len(d.Embedding))
		for i, x := range d.Embedding {
			v[i] = float32(x)
		}
		vectors[d.Index] = v
	}
	return vectors, nil
}
```

```go
// probeTimeout bounds Test connection, which a dead server would otherwise
// hold for the provider's hour-long timeout.
const probeTimeout = 30 * time.Second

// runSetting runs the Test connection button: one small real call per
// ticked kind, each reported with its latency.
func runSetting(ctx context.Context, params json.RawMessage) (any, error) {
	var p protocol.SettingsRunParams
	if err := json.Unmarshal(params, &p); err != nil {
		return nil, invalid("%v", err)
	}
	if p.Action != "test" {
		return nil, invalid("no settings action %q", p.Action)
	}
	c, err := connect(p.Config, p.Secrets["api_key"])
	if err == nil && c.llm == nil {
		err = errors.New("choose a provider and a model first")
	}
	if err != nil {
		return protocol.SettingsRunResult{Message: err.Error()}, nil
	}
	ctx, cancel := context.WithTimeout(ctx, probeTimeout)
	defer cancel()
	res := protocol.SettingsRunResult{OK: true, Message: "Connected"}
	for _, name := range c.settings.Kinds {
		k := kinds[name]
		begin := time.Now()
		err := k.probe(ctx, c)
		check := protocol.SettingsCheck{Name: k.label, OK: err == nil, LatencyMS: time.Since(begin).Milliseconds()}
		if err != nil {
			check.Message = err.Error()
			res.OK, res.Message = false, "A check failed"
		}
		res.Checks = append(res.Checks, check)
	}
	return res, nil
}
```

```markdown
# ai

Connects a language model for other plugins to use, through
[any-llm-go](https://github.com/mozilla-ai/any-llm-go). It offers the `ai`

Tick what the connection is for under **Provides**; chat is the default.

|---|---|---|

| `embed` | `ai.embed` | openai, openai-compatible, gemini, mistral, ollama, llamacpp, llamafile |

A consumer, such as forge-ai, picks an instance that offers the service it
needs. `ai.chat` returns the model's text as it is, including any
`<think>` block, and returns tool calls for the consumer to answer.

  list them, so type the name.
- **Test connection** makes one small real call per ticked kind, a
  one-token chat or one embedded word, and reports each with its latency.
```

## Contracts for later plans

- **Plugin id** `ai`, version `0.1.0`, folder `ai/`, capabilities `["ai", "settings"]`, secret `api_key`.
- **Config keys:** `provider` (enum), `base_url`, `model` (`x-options`), `kinds` (array of `chat`, `embed`; default `["chat"]`).
- **Services** in `initialize`: `ai.chat` for `chat`, `ai.embed` for `embed`, sorted. None for an empty config.
- **Settings:** `settings.options` answers field `/model` only. `settings.run` answers action `test` only.
- **`ai.chat` behavior plan 4 relies on:**
  - `ai.delta` is sent only when `run` is set, one per streamed piece.
  - Text comes back unchanged, so the consumer strips `<think>`.
  - Tool calls come back whole.
  - A refused request (including tools on a model without tool support) is `protocol.CodeAIRejected`, and the consumer decides whether to retry without tools.
  - Rate limits and timeouts are retryable `-32603`.
  - `ai.chat` uses the instance's `model`. The request carries no model.
